# Segurança · Security

## Como o HAXYS CAD protege você
- Roda no seu computador. As funções do servidor interno (arquivos, IA, impressora) só atendem este PC, e a porta do celular só aceita quem tem o código do QR code.
- A ponte MCP só dá à IA ações de CAD fechadas (caixa, furo, extrusão...). A IA **não** roda código no seu computador.
- Chaves de IA ficam só no seu PC, em `Documentos\HAXYS CAD`. Nunca são enviadas para a HAXYS.

## Achou uma falha de segurança?
Não abra uma issue pública. Use **[Report a vulnerability](https://github.com/HAXYS-CAD/haxys-cad/security/advisories/new)**
(aba *Security* do repositório). Respondemos assim que possível.

---

**English:** HAXYS CAD runs locally, the bridge only exposes fixed CAD actions, and AI keys never leave your PC.
To report a vulnerability, please use **Report a vulnerability** in the *Security* tab instead of a public issue.
