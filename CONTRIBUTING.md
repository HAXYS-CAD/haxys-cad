# Como contribuir · Contributing

Obrigado por querer ajudar o HAXYS CAD! · Thanks for helping HAXYS CAD!

## Achou um problema ou tem uma ideia?
Abra uma [issue](https://github.com/HAXYS-CAD/haxys-cad/issues/new/choose) e escolha **Problema** ou **Ideia**.
Conte o que fez, o que esperava e o que aconteceu. Uma imagem da tela ajuda muito.

## Quer mexer no código?
1. Leia [Para quem programa](docs/pt/para-quem-programa.md) para rodar o HAXYS CAD a partir do código.
2. Faça um *fork*, crie uma branch e mande um *pull request* pequeno, com uma mudança por vez.
3. Antes de mandar: `cd app && npm run build` sem erro, e teste a mudança no programa.
4. Textos da tela em português do Brasil, frases curtas e simples.
5. Nunca coloque chaves de IA, senhas ou dados pessoais no código.

Ao contribuir, você concorda que sua contribuição fica sob a [licença MIT](LICENSE).

---

**English:** open an [issue](https://github.com/HAXYS-CAD/haxys-cad/issues/new/choose) for bugs and ideas. For code,
see [For developers](docs/en/para-quem-programa.md), fork, branch, and send a small pull request
(`cd app && npm run build` must pass). Never commit API keys or personal data. Contributions are MIT licensed.
